A one-page pricing page for website design work: ten packages from $20 to $400. Each package is a different kind of website, with its own color, a preview of what that site looks like, and features built for that type of business. The $250 Growth package is marked as recommended.

Open `index.html` in a browser to view it. It's a single self-contained file, so you can host it anywhere (for example, GitHub Pages).

## Scope

Everything listed can be built with Claude alone, with no outside services to sign up for or connect. There is no on-site checkout, booking system, form service, newsletter or analytics: customers order, book and get in touch through buttons that open a pre-filled email, text or phone call. Links to a client's existing pages (ordering apps, social profiles, videos) are fine. Buying domains, business email, Google Business Profile, calls and care plans are not offered.

## What's on the page

- A hero with a desktop and phone mockup, and a strip of what every website includes
- Ten package cards in three groups, each with its own color, site preview and features; each "Choose" button preselects that package in the quote builder
- A "Find your fit" table matching common needs to packages
- Add-ons, a quote builder (total, 50% deposit, balance due at launch), the process, FAQ, and terms

## Editing prices

Prices appear in the hero, the package cards, the "Find your fit" table, the add-ons list and the quote builder. If you change one, update each spot, plus the `PACKAGES` and `EXTRAS` lists in the `<script>` at the bottom of `index.html`.
