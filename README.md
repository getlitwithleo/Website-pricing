# Website Design Pricing

A one-page price sheet for website design work, from a $20 tune-up to a $400 fully custom masterpiece. It's styled like a designer's canvas: each level is an artboard with a sketch of the site you get, with handwritten notes in the margins.

Open `index.html` in a browser to view it. It's a single self-contained file, so you can host it anywhere (for example, GitHub Pages).

## What's on the page

- A ruler showing all five levels to scale on $0–$400
- An artboard for each level with a wireframe sketch, features, turnaround and revision rounds
- A side-by-side comparison table
- Add-ons, a quote builder with a receipt (total, 50% deposit, balance due at launch), how it works, FAQ, and the fine print

## Editing prices

Prices appear in the hero, the price ruler, the level artboards, the comparison table, the add-ons list and the quote builder. If you change one, update each spot, plus the `LEVELS` object and add-on amounts in the `<script>` at the bottom of `index.html`.
