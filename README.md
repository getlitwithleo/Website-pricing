# Website Design Pricing

A one-page price sheet for website design work, from a $20 update to a $400 fully custom build.

Open `index.html` in a browser to view it. It's a single self-contained file, so you can host it anywhere (for example, GitHub Pages).

## Levels

| Level | Name | Price | Pages | Turnaround | Revision rounds |
|---|---|---|---|---|---|
| 1 | Quick Update | $20 | Your existing site | 2 days | 1 |
| 2 | Starter Page | $75 | 1 | 5 days | 1 |
| 3 | Small Business | $150 | Up to 5 | 10 days | 2 |
| 4 | Professional | $250 | Up to 8 | 14 days | 3 |
| 5 | The Masterpiece | $400 | Up to 12 | 21 days | 5 |

| Add-on | Price |
|---|---|
| Extra page | $15 each |

| Logo design | $40 |
| Domain and hosting setup | $20 (included from Level 3) |
| Business email setup | $15 |
| Rush delivery | +$30 |
| Monthly care plan | $25 / month |

## What's on the page

- A price line showing all five levels on a $0–$400 scale
- A row for each level with its features
- A side-by-side comparison table
- Add-ons, an estimate calculator (total, 50% deposit, balance due at launch), how it works, and terms

## Editing prices

Prices appear in the level rows, the comparison table, the add-ons list and the estimate form. If you change one, update each spot, plus the `LEVELS` object and add-on amounts in the `<script>` at the bottom of `index.html`.
